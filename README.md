# 乐湖通管理后台

此仓库仅包含管理后台的静态构建文件。源代码位于私有仓库。访问后台仍需管理员账号和密码；数据请求由现有腾讯 CloudBase 云函数处理。

本次构建来源：`8bf61b8cc2815e7ad5594f07e523bd07dd5d1ff6`。包含课程管理、商城分类与商品图片编辑，以及原有学院、权益和教学管理。课程附件上传与微信订阅推送按云端实际开通状态提供；未迁移或重建真实业务记录。

消息页已修复长用户列表撑高聊天容器、遮挡输入框的问题：列表与聊天记录分别滚动，输入区随窗口高度保持可见。

论坛管理新增「删除帖子」和「删除评论」。删除前需确认并填写原因，删除后学生不可读取且不能恢复，后台保留审核记录。对应云函数同步支持该操作，无需更新微信客户端。

保研服务支持自定义名称、一名固定学生、多位教师与独立交付清单。教师手动记录完成；后台可编辑板块、项目、课时和文件分类，查看交付历史及归档服务。配套云函数和微信客户端一起更新。

交付清单各项可在小程序中打开详情，查看记录与关联文件；后台保留清单修改历史和按项目归属的交付记录。小程序事项直接展示服务内学生待办。

保研服务编辑采用单板块展开，移除计划/实际时长输入。配套小程序支持项目详情直接编辑及关联学生待办，待办完成不自动完成交付。
